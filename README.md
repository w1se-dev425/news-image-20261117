Sums up Tuesday 17 November 2026's world news in one image: a newspaper front page. Lead story: the U.S. strikes an Iranian missile site on Qeshm Island as the Gulf crisis deepens, with an AI-generated editorial illustration of a tanker in the Strait of Hormuz. Also on the page: Ukraine hits the Crimea bridge, markets slide into correction, hackers hit the BBC, CNN and 178 sites, and the Xi–Trump–Putin summit is set for November 19 — plus a briefs strip (Rwanda deportation hub talks, UK sanctions, Pattinson as the new James Bond). The program copies the bundled front page (`entry.png`) to `/output/entry.png`, so it is deterministic and offline: two runs write identical bytes.

## Run it

```sh
python3 main.py
```
